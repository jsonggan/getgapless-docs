This part is for readers who have never designed an interface. If you can answer these three questions, skip it and go to [Chat UI](/docs/frontend/chat-ui):

- A new user opens your app and has no data yet. What should the screen show?
- A request takes ten seconds. What should the user see during those ten seconds?
- Why should "Delete" and "Save" never look the same?

## UI and UX are not the same thing

**UI (user interface)** is what people see and touch. **UX (user experience)** is how it feels to use: whether people reach their goal, how quickly, and how confident they feel.

## The question behind every decision

Every UI and UX choice answers one question: **can the user tell, at every moment, what is happening and what they can do next?**
