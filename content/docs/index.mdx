## Introduction

Gapless Docs helps you design better AI systems/applications for the scenario you are working on.

You may come from data, software, or ML, or you may be new to AI engineering. If you build an AI application or AI system, use these pages as a reference to check your design against.

The docs are also written for AI agents. Each page is plain, structured text, so an agent can read it with few tokens and understand it easily.

## Give it to your agent

When an agent requests a page, the site returns markdown instead of HTML. Markdown is token efficient and easy for your agent to understand, so the agent spends fewer tokens to read a page.

| Need                               | Use                                               |
| ---------------------------------- | ------------------------------------------------- |
| Index of all topics and their URLs | `/llms.txt`                                       |
| Every page in one file             | `/llms-full.txt`                                  |
| One page as markdown               | Add `.md` to the page URL, for example `/docs.md` |
